# Call-Center-Excel-Dashboard
Call Center Data Analysis and Interactive Excel Dashboard
Call Center Data Analysis & Excel Dashboard

Project Overview

This project focuses on analyzing Call Center data and transforming raw data into meaningful insights using Microsoft Excel.
The project includes data analysis, KPI calculation, Pivot Tables, data visualization, and an interactive Excel Dashboard.

Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Analysis
- KPI Analysis

Key Performance Indicators

The dashboard includes the following KPIs:
- Total Calls
- Answer Rate
- Resolution Rate
- Average Speed of Answer (ASA)
- Average Talk Duration
- Average Satisfaction Rating

Analysis

The data was analyzed based on:
- Call volume by day
- Agent performance
- Customer satisfaction
- Average talk duration
- Call topics
